# Contributing

Keep the host game-neutral: game-specific discovery, layouts, and capture behavior belong in adapters and `.gpack` definitions.

For a new game, include its adapter/package source, build command, evidence and dependency sources, and a validation report. Distinguish package integrity, compilation, protocol checks, real game capture, independent audio tracks, feedback, and physical controller testing. Do not label mock output or an offline scan as a working game integration.

When contributing an adapter, document the game version, audio engine, capture method, and validation results. Keep third-party content under its own license and document its origin.

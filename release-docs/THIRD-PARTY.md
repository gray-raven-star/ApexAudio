# 第三方来源与发布范围

- WebView2 SDK：Microsoft，随附原许可位于 `vendor/webview2/LICENSE.txt`（运行包为 `WebView2-LICENSE.txt`）。
- Zig 0.15.2：Zig contributors，开发套件保留 `toolchain/zig/LICENSE` 和完整 lib 目录内的许可文件；不在应用运行包中使用或分发编译器。
- 发布快照使用项目自己的几何波形图标，不包含此前本机使用的驱动品牌图标。
- 游戏媒体、银行、解压库、游戏安装程序、音频中间件 SDK 二进制及官方 X-Haptics 驱动不随包分发。
- Windows、.NET、WebView2 和音频引擎名称用于说明接口和依赖。

项目级开源许可证尚未指定。包作者需要为自行加入的第三方依赖保留来源与许可说明。

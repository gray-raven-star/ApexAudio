# Apex Audio

Apex Audio 使用游戏适配包采集独立音轨。你可以选择送给飞智 X-Haptics 的声音，也可以录音并逐组试听。

解压后运行 `ApexAudio.exe`。需要 Windows x64、.NET 8 Desktop Runtime 和 WebView2 Runtime。补充震动需要受支持的官方 X-Haptics。

1. 从[游戏适配包目录](docs/user/gamepack-downloads.md)下载对应的 `.gpack`。
2. 打开应用，在「游戏适配包」中选择「导入 .gpack」。
3. 启动匹配的游戏版本，在工作台选择适配包并点击「连接采集」。

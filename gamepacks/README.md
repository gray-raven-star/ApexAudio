# 官方适配包源码

打开目标游戏的子目录，先读该包的 `README.md`，了解支持的游戏版本、适配能力和使用限制。`manifest.json` 记录包 ID、版本和游戏匹配条件，`build.json` 提供构建配方。

从仓库根目录构建和校验，步骤见[适配包构建指南](../docs/authoring/build-a-gamepack.md)。有历史定义的包将旧版保存在自己的 `_history/`。用于追溯的原始工作区、制作脚本和旧采集源码收录在公共的 [`_archive/`](_archive/) 中。

已发布版本和附件由发布工作流更新，见[官方适配包下载目录](https://github.com/gray-raven-star/ApexAudio-GamePacks#readme)。

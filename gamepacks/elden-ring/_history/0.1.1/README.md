# 艾尔登法环 0.1.1

在 ApexAudio 的“游戏适配包”中导入本文件。仅匹配清单中声明的 eldenring.exe 程序摘要，游戏更新后可能需要重新适配。

本版将当前选用的已保存配置作为“初始设置”，包括分组名称、文件夹和反馈开关。使用者可继续修改、另存预设，或还原初始状态；更新包不会主动覆盖已有用户副本。

声音开关控制送给 X-Haptics 的补充震动输入，正常游戏声音不变。父子总线和共享混响可能包含重叠内容，分组名称不保证每种声音都能单独分离。

仅限离线单机。包内会拒绝反作弊／受保护启动器进程；不提供关闭保护的功能。

本次更新命名和初始预设，采集程序与原生模块保持原样。已有的原始采集报告若随包保留，测试范围属于此前实现版本；本次没有重复进行游戏或物理手柄测试。

# 怪物猎人：世界

1.0.1 修正 Wwise 2016.2 渲染回调阶段编号，解决已连接但音轨全静音、没有声音补充反馈的问题。更新后须重新打开游戏，避免复用旧采集模块。

117 个可采集分组；另保留 108 个辅助混音条目的元数据，使用 Wwise 2016.2 接口。接口和分组配置均在此包，宿主不包含游戏判断。

默认开启玩家音效、NPC 音效、随从音效、环境和游戏音效。用户可修改分组名称、开关并保存预设。

命名沿用已读取配置：部分名称通过 Wwise 编号与常见名称匹配；未确定名称保留编号，不猜测具体音效。未命名分组的显示大类沿最近已知父类整理。采集保留真实父子关系。

采集模块由项目现有原生代码按 SDK 系列构建。只匹配 game.json 的游戏程序摘要；不改游戏文件。真实录音与震动效果待用户测试。

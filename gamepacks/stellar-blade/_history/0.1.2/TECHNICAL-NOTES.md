# 剑星 0.1.1

0.1.1 修正监听器虚函数顺序：当前游戏从第一个虚函数槽发送音频，旧包误放置了空函数，导致已连接但录不到声音。自测改为通过实际虚函数槽调用。更新后重新打开游戏，以替换旧模块。

试用包，提供 57 个已发现的 Submix 定义，包含主角、无人机、NPC 语音、背景音乐、场景音效等。分组名称来自游戏；部分显示名称译为中文。连接时核对实际存在的对象与父子路由，未载入的分组暂不可采集。

默认开启主角音效、场景音效、击中、格挡、动作、菜单和怪物脚步；用户可以修改命名与开关并保存预设。

使用独立的 Unreal AudioMixer 适配器，主程序不包含剑星判断。仅支持 game.json 记录的主程序摘要，升级游戏后可能需要更新本包。

离线包校验、协议和人工数据回调自测已完成。实际游戏接入尚未测试，录音、反馈和完整分组覆盖不能视为已验证。完整配置格式见 adapters/Unreal/README.md。

# .gpack 格式（V1 清单与安装管理）

`.gpack` 是普通 ZIP，根目录直接放 manifest.json，不能多套一层文件夹。目录内可包含 EXE、DLL、私有运行环境、资源、作者预设及说明。单包最大 1 GiB、10000 条归档记录。

本页清单示例为包含独立程序的 V1 格式；FMOD JSON 配置包的试验格式见[共享后端说明](../development/v2-trial.md)。下述版本安装与当前选择规则同时用于已支持的 V1 和 JSON 配置包，不要求旧包重新制作。

```text
manifest.json
adapter.exe
adapter-private-runtime/  # 可选
modules/                 # 可选
presets/author.json
resources/               # 可选
```

## manifest.json

```json
{
  "schemaVersion": 1,
  "id": "author.game-name",
  "name": "游戏名称",
  "version": "1.0.0",
  "author": "发布者",
  "source": "发布页面或来源说明",
  "description": "此包实际支持的版本和能力",
  "protocolVersion": 1,
  "entryPoint": "adapter.exe",
  "demo": false,
  "games": [{"executable": "Game.exe", "sha256": "程序SHA256"}],
  "presets": ["presets/author.json"],
  "files": {"adapter.exe": "文件SHA256", "presets/author.json": "文件SHA256"}
}
```

| 字段 | 规则 |
|---|---|
| schemaVersion / protocolVersion | V1 都为 1，不兼容版本在启动前拒绝 |
| id | 3～80 字符，首字符小写字母／数字，其余小写字母、数字、点、短横线；发布后固定 |
| version | .NET Version 格式，如 1.0.0 |
| name | 非空显示名称 |
| author / source / description | 作者、来源及支持范围，导入和首次执行时展示；普通字符串，不执行内容 |
| entryPoint | 包内相对 EXE 路径，不接受外部路径或命令行 |
| demo | 仅演示使用 true，允许不匹配游戏进程，不自动连接 |
| games | 真实包至少一条；executable 为文件名，sha256 可省略，省略表示由适配器自行核对版本 |
| presets | 作者预设相对路径，可为空；无作者预设时建立全关闭的空用户配置 |
| files | 所有文件（除 manifest.json）相对路径与 SHA256；缺失、变更、未登记文件均拒绝 |

JSON Schema 位于 `schemas/manifest.schema.json`。运行时还做文件完整性、路径、格式及预设语义校验。

路径统一用 `/`，禁止绝对路径、盘符、反斜线和越过根目录的 `..`。完整性摘要不等于作者身份签名。宿主展示来源，并按包清单摘要保存首次运行许可。

## 安装、当前选择与移除

同一包 ID 的多个版本可以同时安装。新导入保存在 `data/pack-versions/<id>/<version>`，旧 `data/packs/<id>` 安装记录继续被发现；没有显式选择记录时，保留旧安装的原选择。旧包内容不因升级安装管理方式而转换。

导入只增加已安装版本，不自动设为当前默认，即使首次导入也需要明确选择。相同 ID/版本的相同内容可重复导入；清单摘要不同则拒绝覆盖。当前默认按包 ID 独立保存，JSON 包只有全部固定后端依赖可解析且内容校验通过时才能设为当前；缺依赖的新包可以安装，不取代原选择。V1 仍运行包内程序，不要求声明共享后端。

JSON 后端带 `support` 声明时，设为当前前对全部 Profile 检查声明、参数尺寸与版本，并由主程序内匹配的第一方静态验证器检查字段、组合及必需模块摘要声明；缺少匹配验证器时返回不支持，不能启用。失败保留旧默认；准备会话时再次检查，失败释放版本使用保护。这些检查不运行后端或连接游戏，静态通过不表示实机兼容性已经验证。Owner 0.2.0 等无支持声明的旧后端保留原校验与运行流程。

“已安装”“当前默认”“会话正在使用”分别表达文件存在、下次连接默认使用和本次连接固定使用的版本。设为当前或清除默认只影响之后的连接，不改正在运行的会话。连接开始使用的包版本按 ID、版本和清单摘要固定，不能在确认后因默认选择改变而换成另一版。

移除版本前必须先改选或清除它的当前默认状态；会话仍在使用的版本也不能移除，需先断开。移除仅删除该包版本目录，不删除其他版本、共享后端、用户预设或录音。回退通过将已安装旧版设为当前完成，继续使用旧版声明的依赖；加载采集 DLL 时发现版本冲突仍须按提示重启游戏。软件不自动下载更新或后端。

## 识别

以进程主程序名称筛选，再按可选 SHA256 匹配。文件名比较不区分大小写，摘要比较不区分大小写。进程不可访问且包要求摘要时，不猜测匹配。多个包匹配时用户选择。

作者应避免把机器上的固定安装路径写进包。未知程序版本不能套用旧内存地址；版本拒绝和访问失败须由 Adapter 返回清楚原因。

## 引擎专用配置

宿主不解释 game.json 的引擎字段。Wwise、FMOD、Unreal 等适配器各自解释自己的配置，并输出同一协议。

Unreal AudioMixer 示例和字段格式见 `adapters/Unreal/README.md`。游戏差异包含设备地址链、名称池布局、监听方法地址、稳定分组名称和初始预设；只支持包声明并核对的游戏文件，不代表所有虚幻版本已覆盖。

包卡片按已安装版本显示名称、版本、“包含独立程序”或“JSON 共享后端配置”、作者与来源，以及当前默认、会话使用和就绪问题。JSON 包逐个 Profile 显示固定后端 ID、版本、变体、是否已安装及已声明的参数格式版本；后端已安装不等于包参数有效或可以设为当前。就绪问题与操作错误给出具体原因和恢复操作，不能启用的版本禁用“设为当前”，失败保留旧默认。author、source、description 是来源声明及首次运行确认信息，不参与音频逻辑，不表示官方认证。

# 当前能力与限制

Apex Audio 支持适配包导入、更新和卸载，作者预设与用户副本，声音分组编辑，独立音轨录音、试听及 X-Haptics 声音输入转送。游戏采集能力由对应 `.gpack` 提供。

## 支持范围

- Windows x64，同时连接一个游戏／适配器。
- 适配包只支持其声明并核对的游戏版本。游戏更新后可能需要更新适配包；各游戏实际测试范围见随包 README。
- 分组名称、分类和父子关系来自游戏元数据、包作者或用户标注；程序不使用 AI 自动识别声音含义。
- 录制独立音轨与选择反馈声音分别控制。父分组可能包含子分组的内容，修改显示分类不会进一步分离声音。
- 补充震动需要兼容的官方 X-Haptics。驱动版本更新后可能需要更新本程序的反馈模块。
- 主程序不提供任意游戏的自动适配、在线包仓库或自动依赖安装，也不自动转换旧工具的录音格式。

## 连接与隔离

程序不自动请求管理员权限。游戏访问失败会报告原因；选择提升运行时，宿主与适配器须使用同一账户。项目不提供绕过保护或反作弊的流程。

适配器在独立进程运行，其普通崩溃不会直接结束主窗口；错误采集代码仍可能影响游戏，独立进程也不是第三方代码安全沙箱。只导入来源可信的包，并按[使用说明](settings-recording.md)连接和录制。

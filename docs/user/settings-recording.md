# 连接、录制和主题设置

勾选的声音分组送给 X-Haptics 生成补充震动，不改变游戏自身音量。父分组可能包含子分组的声音；显示文件夹只整理列表，不改变实际路由。

修改作者预设后，第一次保存会建立用户副本；之后“保存”覆盖该副本，“另存为”建立新副本。“还原作者初始状态”载入工作台所用包版本的作者预设，并标记为未保存，不会立即覆盖用户副本。移除适配包版本保留用户预设与录音。

在“游戏适配包”页面导入 `.gpack` 后，点击“设为当前默认”选择后续连接使用的版本。导入不会自动改默认；首次导入也需选择。JSON 配置包提示缺少共享后端时，先导入对应 `.gbackend`，再设为当前。页面区分“包含独立程序”和“JSON 共享后端配置”，并显示作者与来源。

同一包可以保留多个版本，不同游戏各自有当前默认版本。“当前默认”表示下次连接使用，“会话正在使用”表示本次采集固定使用；改默认或“清除默认”不停止当前会话。工作台连接状态旁显示本次版本，下次连接采用届时的当前默认。

要回退，直接将已安装旧版设为当前默认；它的内容和所需后端必须仍可用。要“移除此版本”，先改选或清除该版默认，并结束仍使用它的会话。移除不会删除其他包版本、用户预设和录音。遇到采集 DLL 版本冲突时，按提示重启游戏后再连接。

录制设置均在“应用设置”。默认定时 10 秒、无倒计时；手动模式也在一分钟结束。快捷键默认 Ctrl+Alt+F9，在输入框内重新按组合后保存。手柄按键通过“录制按键”短按绑定，不默认使用截图键。不要与旧 Hub 的模式切换绑定同一按键。

录音保存全部可采集分组，不随反馈开关缩减；单次最长一分钟。试听只播放所选录音轨道，不修改原始录音。建议先暂停游戏，避免游戏声音混入听感。

录制开始／结束可发提示音，不显示前台窗口、不抢游戏焦点。倒计时期间再触发可取消。录制期间再触发可提前停止。音频停止后继续短暂收集遥测，不会延长音频录制。

自动连接只处理已信任、具有当前默认版本且唯一匹配的游戏／适配包，不启动游戏。自动反馈在游戏连接后转送声音；X-Haptics 没运行且允许自动启动时，后台启动配置的程序。驱动退出后再次运行时重建反馈连接，不要求重启游戏。用户手动关闭反馈会保存该偏好。

游戏切到后台或暂停音频时，Wwise 采集保持连接并显示等待恢复。真正断开后，自动连接每次失败至少间隔 5 秒重试；连接成功后按原来的反馈开关恢复声音转送，并保留当前未保存的分组设置。用户手动断开后不会自动重连。

反馈状态分别显示关闭、等待采集连接、等待 X-Haptics 读取、通道就绪但没有选中声音、所选声音正在送入 X-Haptics。转送状态和信号强度来自桥接实时数据，不代表马达实测。

录音界面可显示声音补充分量、引擎合成输出或两者，曲线取决于驱动实际记录的数据。正式版驱动的曲线是离散查询点，点间数据未知，短促震动可能漏记。历史录音已有最终输出时可直接查看；没有单独补充分量的录音不能从声音轨道推算补齐。

深色／浅色主题切换立即保存。软件的支持范围见[当前能力与限制](capabilities.md)。

# 当前交付

这是独立声音工具的 V1。包括本地完整包导入／更新／卸载、独立 Adapter 进程、命名管道控制与二进制 PCM、作者／用户预设、显示分类编辑、独立音轨录音与试听、X-Haptics 时间轴及输入转送。

演示包仅生成不同内容的测试音轨。额外迁移包来自旧配置，并在清单中说明来源与程序版本。新增游戏支持必须由适配包提供；此版本没有自动扫描任意游戏接口的承诺。

## 当前边界

- Windows x64；一个活动 Adapter。
- 标准输入为 48 kHz 双声道 PCM16；其他格式由适配器转换。
- 名称、分组分类由游戏元数据、作者或用户提供，不使用 AI 猜测。
- V1 只实现 independentPcm 音轨消费；activity-only、事件、对象身份信息暂未定义传输。
- 运行时资源读取、新引擎识别、在线包仓库、自动依赖安装不在本轮范围。
- X-Haptics 转送沿用已有桥接实现，只匹配 xh-support.json 中记录的引擎版本。更换官方驱动后需更新反馈模块。
- 不自动请求管理员权限。游戏访问失败报告原因；若用户选择提升运行，须保证宿主与适配器账户一致。没有绕过保护或反作弊的流程。
- 隔离 Adapter 可防止其普通崩溃拖垮主窗口，不能保护游戏免受错误适配代码影响，也不是第三方代码安全沙箱。
- 历史录音仍在旧工具中，V1 没有自动改写旧格式。

旧软件、配置和录音保留在原目录；新项目不继续携带旧扫描试验或旧 UI 功能。

## “关于声音采集”建议正文

勾选的声音分组会送给 X-Haptics 生成震动。分组名称、分类和开关状态都可以修改，再保存为自己的配置。

开始录制后，工具会分别保存各分组的声音，最长一分钟。在“录音与试听”选择一条音轨，即可只听这一组；选择相同时间区间，可以逐组比较。

震动曲线来自 X-Haptics，可与声音时间轴对照。它表示驱动报告的震动强度；如果两条时间轴看起来有偏差，可以调整“震动偏移”。

部分父分组包含子分组的声音，试听内容重叠可能是游戏本身的分组方式。修改列表分类不会重新分离游戏声音。

## 新控件补充说明建议

- 反馈声音强度：1.00 保持原强度；这里只调整送给 X-Haptics 的声音，不改变耳机音量。
- 键盘快捷键：点击输入框后按组合键，再保存。游戏在前台时也可使用。
- 手柄快捷键：点击“录制按键”，短按要绑定的手柄键。不要与旧 Hub 的模式切换使用同一个键。
- 定时录制：按一下开始，到设定时间自动结束；再按一下可提前结束。
- 手动录制：按一下开始，再按一下结束，最长一分钟。
- 开始倒计时：0 秒立即录制；设置倒计时可留出返回游戏的时间。

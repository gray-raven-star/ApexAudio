# 架构

## 责任边界

```
本地 WebView2 UI
    │ JSON 界面命令／状态
Desktop 宿主
    │
Application 工作台操作
    ├─ Core：包、预设、进程识别、IPC、录音
    └─ XHaptics：输入转送与只读震动遥测
    │ 控制管道＋二进制音频管道
游戏 Adapter 独立进程
    └─ 包内采集实现或固定版本的共享后端／原生模块
```

支持 `realtimeMix` 的适配包另提供采集端混音共享缓冲区，X-Haptics 反馈模块直接消费它。分组选择由工作台通过控制管道下发；独立 PCM 管道供活动显示、录音与试听使用。反馈不等待宿主录音写盘。主程序按能力与格式选择路径，不按游戏名称、SDK 或引擎判断。未声明此能力的旧包继续使用通用宿主混音。

`Contracts` 不引用 UI、具体引擎或具体游戏。`Core` 不引用 Wwise、游戏文件格式或注入逻辑。`Windows` 是可选的内部进程调用辅助代码，只供需要它的适配器／反馈模块使用。

Desktop 不加载第三方适配器 DLL。V1 启动已校验包内的 EXE，JSON 配置包则解析并启动其固定版本的共享后端。Adapter 崩溃关闭自己的管道，宿主停止会话、结束录音、关闭反馈，界面继续运行。独立进程不是安全沙箱。

首版同时连接一个游戏／适配器。多个匹配包或多个游戏实例存在时不自动猜测。包作者可以使用任何语言，只需遵循 IPC 协议。

## 用户数据

- `data/pack-versions/<id>/<version>`：新导入的不可变包版本；导入不改变当前默认，同版本不同内容拒绝覆盖。
- `data/packs/<id>`：兼容发现旧单版本安装，保留原包，不要求重新制作。
- `data/package-current.json`：按包 ID 保存当前默认选择；改选只影响下次连接。
- `data/package-leases/`：正在使用的包版本保护记录，在后端退出前阻止删除。
- `data/backends/<id>/<version>`：已校验的共享后端安装，不同版本并存。
- `data/presets/<pack-id>`：用户副本，与作者原稿独立。
- `data/recordings/<session-id>`：独立 WAV 和 session.json。
- `data/trusted.json`：首次运行许可按清单摘要记录，更新包后重新确认。
- `data/settings.json`：端口、增益、自动连接偏好。
- `data/webview`：界面运行缓存。

当前默认、已安装版本与会话固定版本相互独立。JSON 包选择当前默认前必须补齐其固定后端依赖；当前或会话在用版本不可直接移除。包版本移除保留用户预设、录音及其他版本。完整接口约定见[FMOD 本地架构草案](fmod-v2-architecture.md)，草案中的未实现部分不能由这些目录说明推断为已完成。

源代码与这些运行数据分开，`dist`、`artifacts`、`bin`、`obj` 不属于源码。

## 状态与真实性

包清单只负责识别。Adapter 运行时报告采集能力；收到某组有效 PCM 后，本体才将其标记为“已收到独立音轨”。这只能证明收到符合协议的数据，无法从任意第三方程序输出自动证明声源语义真实；作者仍需保证独立音轨没有伪造。Mock 用不同波形验证运输与录音链路。

显示文件夹不改变实际混音层级。反馈选取依据实际父子路由：包含子组的父组被选择时，不再把其已选子组叠加。独立录制仍保留各组，可能存在真实的父子内容重叠。

包中的游戏版本规则与适配器二次核对共同生效。V1 不提供自动解包、运行时资源扫描、SDK 猜测、AI 或反作弊绕过。

## 连接恢复

自动连接每次失败至少间隔 5 秒重试，用户手动断开后抑制自动连接。每条断开通知带连接编号，过期通知不影响新连接；自动恢复保留当前未保存的分组设置。正常关闭适配器的管道结束不会上报为故障。

当前分轨录音和活动显示使用 independentPcm；支持 realtimeMix 的包可直接提供反馈混音。activity-only、事件和对象身份信息尚未定义传输。主程序不执行资源容器读取或新引擎识别，包作者的调查工具独立使用。
